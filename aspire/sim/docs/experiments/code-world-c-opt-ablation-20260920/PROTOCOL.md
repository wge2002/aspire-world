## 必须能被验证的机制

1. **观测约束。** 抓取、移动、释放后的公开观测真正进入 world；记录证据来源与时序。`phase=complete` 不是自评标签，commanded pose 不是 measured object pose。
2. **可执行彩排。** 候选 policy 使用相同 API 调用生成 world 的预测实现，在实际执行前记录预测、失败类型、是否筛掉候选。区分代码崩溃检查、可证伪语义检查和任务成功预测，不能统称“预测成功”。
3. **诚实回放。** 从开发 tape 按调用顺序读取。修复后的动作名或参数一旦与旧轨迹分歧，就停止并报告反事实不受支持；不得继续用旧未来观测验证新动作。
4. **自评。** 生成目标谓词依赖 world 状态与可见证据，输出 true/false/unknown 和依据。环境 task_completed 只给外部 evaluator，不进入 policy/world。本轮仍沿用有开发反馈的 Fix Loop，不宣称已实现无 oracle 的外循环。
5. **参数来源。** LLM 写结构；从开发观测估计数字并登记来源。API 定义常数需遵守其真实参照点和裁剪语义。无数据则承认未标定，不靠放宽阈值掩盖未知。
